# Master Vision

## Mission
Build the operating system for nursing education — not just an NCLEX question site, but an interconnected knowledge network where every concept links to every related concept, and learning adapts to each student.

## The core idea: the Nursing Knowledge Engine (NKE)
Everything revolves around one central object. Every page, question, AI response, and search result plugs into it. A single disease (e.g. Heart Failure) connects to its symptoms, medications, labs, interventions, procedures, videos, images, NCLEX questions, NGN cases, flashcards, memory aids, specialties, and anatomy.

The differentiator is the **Nursing Knowledge Graph**: instead of separate pages, every concept is a node and every relationship is an edge. When a student misses a question on hyperkalemia, the system knows they may also need potassium physiology, ECG changes, kidney disease, ACE inhibitors, spironolactone, dialysis, and related labs — and builds a personalized learning path from those relationships rather than just marking the answer wrong.

## Goals
- Help students learn **more efficiently**, not just answer more questions.
- Connect every concept so understanding compounds.
- Personalize study through an adaptive knowledge map per student.
- Provide an AI tutor (Esi) that teaches reasoning, not just answers.

## Competitive positioning
Most competitors are **content companies** (they write pages). Must Love Scrubs is a **software company** with a durable foundation — schema, API contracts, content standards, and AI rules — so new features (community, instructor tools, mobile app, simulation) plug into one ecosystem instead of being rebuilt each time. The knowledge graph is intellectual property that is hard to copy.

## Content pillars (long-term)
1. **Nurse Dictionary** — 40,000+ terms, each fully linked.
2. **Disease Encyclopedia** — full clinical templates per condition.
3. **Medication Center** — full drug templates.
4. **Lab Center** — normal/critical values, causes, nursing actions.
5. **Procedure Library** — equipment, steps, complications, questions.
6. **Clinical Skills Library** — delegation, prioritization, SBAR, ethics.

## Platform surfaces (long-term vision)
Question engine (all NGN item types), Esi AI tutor, personal dashboard, smart study engine, memory engine (spaced repetition), visual learning, simulation center, community, career center, mobile app, ScrubTV. **Not all of this is v1** — see `04-scope-v1-webapp.md` for what we build first.

## Guiding principle
Prove quality before scale: build one complete "gold standard" module end-to-end, then use it as the template for hundreds of topics. Target 5,000–8,000 questions as a **launch milestone, not a ceiling**; the architecture must support growth well beyond that without redesign.
